# Wallpaper

The wallpapers are third-party art, so they are not in this repo. Use your own, or put files with these names in `~/Pictures/Wallpapers/` and the layout picks them up:

| File name | Used for |
|---|---|
| `lain-wired-live.mp4` | Live desktop wallpaper (Smart Video Wallpaper Reborn, looped) |
| `lain-wired-exkqk8.jpg` | Still image fallback |

Any other video or image works. Change it in Desktop > Configure Desktop and Wallpaper, choose the "Smart Video Wallpaper Reborn" plugin and point it at your file.

The lock screen background is set inside the NieR look-and-feel package, and the login screen uses `bg.mp4` / `bg.png` (see [BOOT-LOGIN.md](BOOT-LOGIN.md)).
