# Fonts

| Font | Used for |
|---|---|
| JetBrainsMono Nerd Font | terminal, fixed width, clock |
| Geist / Geist Mono | UI accents |
| Google Sans Flex | UI |
| Material Symbols | icons in widgets |
| Noto Sans | window titles (Medium) |

Install fonts to `~/.local/share/fonts/` and run `fc-cache -f`. Fonts are not bundled, get them from their projects.
